# overlay-frontend 진행 상황

Next.js(App Router) 기반 OBS/Xsplit 브라우저 소스용 오버레이 앱. `:3002`에서 서비스. api-frontend(콘솔)에서 완전히 분리된 별도 프로젝트다.

## 개요

계정당 후원 알림/채팅/게임 3종 위젯을 관리하고, 각 위젯은 고유 토큰이 붙은 공개 URL(로그인 불필요)로 OBS 브라우저 소스에 추가해서 사용한다. api-server의 `/overlay` 소켓 네임스페이스로 실시간 이벤트를 받는다.

## 주요 기능

### 설정 페이지 (로그인 필요)
- `/` — 위젯 허브: 후원/채팅/게임 3개 카드 + 오버레이 전용 연결 스트리머 관리
- `/donation`, `/chat`, `/game` — 각 위젯 설정 (OBS URL 표시/복사, 폰트 크기, 후원 구간별 텍스트/이미지, TTS 켜기, 채팅 최대 표시 개수, 게임 발동 조건 등)
- api-frontend와 로그인 세션은 공유되지 않음(같은 계정으로 각각 로그인 필요) — 데이터(DB)는 같은 걸 씀

### OBS 렌더 페이지 (로그인 불필요, 토큰 기반)
- `/donation/[token]` — 후원 알림. **큐 구조**로 동작: 소켓으로 들어온 이벤트를 큐에 쌓고, 하나씩 순서대로 1초 등장 → (TTS 재생 또는 2초 고정 대기) → 1초 퇴장 재생. TTS 사용 시 구글 TTS URL을 `<audio>` 엘리먼트로 로드(fetch가 아님 — CORS 우회 목적)해서 `canplaythrough`까지 기다린 뒤 재생 시작, `ended`로 다음 단계 진행
- `/chat/[token]` — 채팅 피드. 새 메시지 push 시 컨테이너와 `document`/`body` 모두 스크롤을 맨 아래로 내림
- `/game/[token]` — 후원 계기 룰렛 미니게임(구현은 룰렛만)

### 공용 로직
- `useOverlayJoin` — `/overlay` 소켓에 토큰으로 join, 연결 상태/설정값 반환
- `decodeEvent` — Snappy 압축 해제 + JSON 파싱

### `/sample` — 실험용 페이지 (참고 디자인 검증용)
- 실서비스 위젯이 아니라, 카지노 슬롯머신 스타일 후원 알림 연출을 미리 실험해보는 독립 페이지
- 카드 5장이 세로로 트랙을 이루고, 카드 뒤집기(`?` → 숫자) + sparkle 파티클 + 선택 카드 강조(스케일/글로우) 애니메이션 구현
- 후원 시 표시할 애니메이션 스타일을 2종(테두리 애니메이션 / 텍스트 네온사인) 중 선택해서 큐로 재생해보는 구조
- **작업자가 SCSS/JSX를 직접 계속 갈아엎으며 다듬는 중** — 실서비스 `/donation`에는 아직 반영 안 됨

## 알려진 이슈

- `/donation`, `/chat`, `/game` 실제 위젯 디자인은 `/sample`에서 만든 화려한 스타일이 아직 반영 안 된 기본 카드 스타일 그대로임
- `mission` 소켓 이벤트를 받아서 표시하는 기능 없음 (api-server는 이제 실시간으로 내보내지만 소비하는 쪽이 아직 없음)
- SOOP 미션 관련 TTS/알림은 위 collect-socket 이슈(SOOP 미션 미수집) 해결 전까지는 애초에 이벤트 자체가 안 옴
